# Default monthly tenancy agreement format

Use this user-approved format when asked for a tenancy agreement, rent agreement, monthly tenancy, or kirayanama. The user explicitly requested saving the generated English agreement as the default on 30 September 2026. This approval covers the reusable format, not the facts of future matters.

## Selection and language
- Preserve the source document's language unless the current user expressly requests a different language. For an English source or an unspecified new agreement, use English. Never infer Hindi from older tenancy tasks or the user's location.
- Keep current-source wording, clause order, substantive terms and property description when told "same, only change rent/date". Do not silently rewrite clauses or add legal provisions.
- Read every attached source page using the intake workflow. Use that matter's names, relationships, addresses, identifiers, amounts and terms. Never reuse prior client details.
- Use the latest explicit rent amount when the user's opening shorthand and later instruction differ. Do not hard-code Rs.5,000, Rs.5,500, or any other sample amount.
- Interpret "from today" using the current date in Asia/Kolkata. Update execution/start dates and calculate the corresponding end date only when renewal from today is instructed. Preserve a supplied term. For an 11-month term commencing 30/09/2026, the end date is 29/08/2027. Never freeze these example dates into a new matter.
- If a source clause is internally ambiguous, do not silently change its allocation of obligations. Flag a material ambiguity and preserve the instructed wording until clarified.

## Exact approved PDF layout
- A4 portrait, clean black text, no decorative border.
- Match the approved English PDF's sans-serif type: Helvetica 12.5 pt body, 19 pt leading, justified text, 10 pt paragraph gap. Use Helvetica-Bold for headings, party names, party designations and masked identifier blocks. This tenancy-specific approval overrides the general Times New Roman petition default.
- Left margin 66 pt; right margin 55 pt; bottom margin 45 pt.
- Leave 200 pt (approximately 70.6 mm) blank at the top of EVERY page, including continuation and signature pages. This reproduces the requested four-to-five-finger gap. Do not apply the petition-only first-page gap rule to tenancy agreements.
- Center and bold-underline the title, "BY AND BETWEEN", "A N D", agreement-terms heading and "SCHEDULE".
- Keep "WITNESSES:" bold and underlined at the left. Use two numbered blank witness lines. Keep bold-underlined first-party and second-party signature labels at the right with generous signing space.
- Keep a small "Page | n" footer, Helvetica 9 pt, at the bottom right.
- Use the approved four-part sequence below. Keep paragraph/clause blocks intact where possible. If a different matter is longer, add pages with the same top gap rather than reducing font size or dropping wording.
- Produce a fresh unsigned agreement. Never copy scanned signatures, notarial stamps, stamp-duty receipts or payment identifiers into the reusable document.
