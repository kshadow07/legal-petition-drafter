# Legal Petition Drafter

Start with [AGENTS.md](AGENTS.md), the single authority for routing and formatting.

For the user's father's Jamshedpur district-court practice. **English defaults to Times New Roman (Tinos when unavailable)**, not Courier. Courier is opt-in for explicit typewriter-style requests. Hindi uses the approved Noto Sans Devanagari/DejaVu Sans rendering. Court petitions use a three-finger first-page gap only; deeds follow their own reference layout. Deliver requested PDFs directly.

For a family partition deed, use [the dedicated guidance](skills/family-partition-deed/SKILL.md): centred and underlined AND between party blocks, schedules A/B/C, confirmed boundaries, and witness/signature blocks at the end of the deed. The example deed is style-only and does not supply new case facts.

The Hindi skill includes an approved, anonymized `सेवा में` administrative application layout and a reusable WeasyPrint renderer. It is not an FIR form. Keep client facts out of reusable assets. Read source images directly and never guess unclear names or numbers.
